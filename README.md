## 🌟 Tentang KageWire

**KageWire** adalah platform streaming Anime, serial Donghua (animasi 3D Tiongkok), dan portal pembaca Manga / Manhwa berstandar enterprise yang didesain dengan estetika dark cinematic modern, bebas iklan mengganggu, dan berkinerja tinggi.

Seluruh data anime, jadwal rilis episode, link streaming multi-server, serta gambar halaman komik terintegrasi langsung dengan ekosistem **SankaApi** (`https://www.sankavollerei.web.id`).

---

## ✨ Fitur Utama

- 🎬 **Anime Hub (Otakudesu & Samehadaku)**: Update anime ongoing harian, rilisan tamat, dan film anime dengan subtitle Indonesia.
- 🐉 **Donghua Hub (Donghub)**: Animasi 3D/2D asal Tiongkok populer (kultivasi, petualangan dunia dewa) dengan streaming player responsif.
- 📖 **Comic & Webtoon Reader (Shinigami)**: Pembaca manga, manhwa, dan manhua berkecepatan tinggi dengan mode scroll vertikal terus-menerus dan kontrol zoom.
- ⚡ **StreamPlayer Canggih**: Player 16:9 responsif dilengkapi fitur pemilih server, mode bioskop (Theater Mode), serta navigasi episode berikutnya/sebelumnya.
- 🔍 **Pencarian Terpadu (Unified Search)**: Cari judul anime, donghua, atau komik secara instan dari satu bilah pencarian.
- 📑 **Watchlist & Riwayat Lokal**: Simpan episode terakhir dan daftar favorit Anda yang otomatis tersimpan di peramban tanpa perlu login.

## 🚀 Memulai (Quick Start)

### Prasyarat
- **Node.js** >= 18.x (Direkomendasikan Node.js 20 atau 22)
- **npm** atau **pnpm** / **yarn**

### Instalasi & Menjalankan

```bash
# Clone repository
git clone https://github.com/leapwithluvi/kagewire.git
cd kagewire/frontend

# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev
```

Buka peramban Anda di [http://localhost:3000](http://localhost:3000) untuk menikmati KageWire.

### Production Build

```bash
# Build untuk rilis produksi
npm run build

# Menjalankan server produksi
npm start
```
